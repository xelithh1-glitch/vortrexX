Исправленный проект Vortex для Fabric 1.21.11

Это исходники для сборки, а не готовый проверенный JAR.

1. Распакуйте ZIP. Файлы build.gradle, settings.gradle, gradle.properties,
   папки src и .github должны находиться непосредственно в корне репозитория.
   Не загружайте весь проект во вложенную папку.
2. Удалите старые Java-файлы и fabric.mod.json из корня, если они там остались.
   Актуальные файлы находятся в src/main/java и src/main/resources.
3. Запустите Actions -> Build Fabric JAR -> Run workflow.
4. При успешной сборке скачайте vortex-fabric-jar.
   Для установки используйте vortex-fabric-0.1.0.jar, без суффикса -sources.

Сборка использует Java 21, Gradle 9.2.1, Loom 1.14.10,
Minecraft 1.21.11, Loader 0.18.4 и Fabric API 0.141.1+1.21.11.
Проверка verifyModJar отклоняет архив, если в нем отсутствуют классы,
fabric.mod.json, переводы или не подставлена версия.

Локальная сборка не завершена из-за ограничений среды исполнения.
Компиляция и запуск Minecraft не подтверждены.
Меню и HUD реализованы; игровые модули являются визуальными заглушками.
